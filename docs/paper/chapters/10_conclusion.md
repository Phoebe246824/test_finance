# 10 结论

本文围绕银行零售反欺诈与反洗钱场景，设计并实现了基于端侧 AI 的多智能体风险预警系统 Sentinel Edge。系统将本地模型推理、黑名单过滤、向量暂存、历史回捞、关系图谱、多维风险评分、趋势预测和人工复核整合为端到端闭环，解决了传统规则系统对组合风险识别不足、人工跨系统串联效率低、云端推理不适合敏感金融数据等问题。

在系统设计上，Sentinel Edge 通过低风险事件暂存和高风险事件回捞机制，将普通事件转化为后续风险研判的历史上下文；通过关系图谱将客户、账户、设备、商户和风险信号组织为可交互证据链；通过多维风险评分方法使风险等级具有可解释依据；通过趋势预测报告和人工复核动作帮助分析员完成业务闭环。

在硬件适配上，系统基于 AMD 锐龙 AI MAX+ 平台，设计了 CPU、GPU、NPU 和统一内存的协同分工。CPU 负责流程编排、业务逻辑、OpenAI 兼容接口调用和数据库访问，GPU 通过 llama.cpp 承载 Q6_K_M 量化后的 Qwen3.6-35B-A3B 大模型推理，NPU 通过 vLLM 承载 BGE M3 Embedding 与 BGE Reranker v2-m3 推理，统一内存支持多模型、多数据库和 Web 服务并行运行。该设计使金融敏感数据能够在本地完成处理、分析和展示，为银行内网智能风控提供了隐私友好、低延迟、可追溯的实现路径。

后续将进一步补充 AMD 平台上的性能、能效和量化实验数据，并扩展更多金融风险场景，使系统从演示原型逐步走向可试点落地的端侧金融风控工作台。
