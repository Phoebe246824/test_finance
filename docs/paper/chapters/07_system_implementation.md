# 7 系统功能实现与端到端 Demo

## 7.1 风险分析页面

风险分析页面是系统的主流程入口。用户可以输入一段金融事件文本，也可以从内置 Demo case 中选择样例。点击分析后，页面展示风险等级、风险分数、事件状态、摘要、黑名单命中、关系图谱、趋势预测报告和 JSON 报告导出按钮。该页面使用前端状态持久化机制，用户跳转到其他页面后再返回，分析文本、分析结果和图谱仍会保留。

风险等级展示遵循统一规则：未命中高危规则的事件按低风险展示并暂存；`risk_score >= 0.70` 显示高风险；`0.35 <= risk_score < 0.70` 显示中风险；`risk_score < 0.35` 显示低风险。这样可以避免同一事件在风险分析页、事件库和事件详情页显示不一致。系统核心界面如图 6 所示。

## 7.2 事件库与事件详情页面

事件库用于查询历史分析结果，支持查看已分析事件和暂存事件。事件详情页展示事件原文、风险等级、风险分数、事件类型、维度分数、黑名单命中、趋势报告和关系图谱。分析员可以在详情页提交复核动作，例如建议冻结、已复核或误报标记。复核结果会写入本地数据库，作为后续优化和审计依据。

事件详情中的图谱节点和边均来自 Neo4j 中的真实节点、标签、关系类型和属性[6]。点击节点可以查看实体编号、名称、标签、属性和相关边；点击边可以查看来源节点、目标节点、关系类型和关系属性。

## 7.3 人物图谱页面

人物图谱页面支持按客户编号或客户名称搜索。系统返回与该人物相关的账户、设备、商户、事件和风险信号，并以可交互图谱展示。分析员可以点击任意节点继续扩展关联节点，用于发现团伙欺诈、共享设备、资金归集和多事件串联等风险网络。人物图谱的交互示例已在图 4 中展示。

## 7.4 黑名单管理页面

黑名单管理页面用于维护人员黑名单、关键词黑名单和高危事件样本。系统支持新增、删除、启用和停用黑名单条目。黑名单过滤位于风控流程前置阶段，可以快速识别显性高危对象，并减少不必要的大模型推理开销。

## 7.5 总览与系统状态页面

总览页面展示事件总量、高风险事件数量、低风险暂存数量、平均风险分数、趋势报告覆盖率、风险分布和最近事件。系统状态页面展示后端服务、Redis、Milvus、Neo4j 和 SQLite 的健康情况，方便演示时确认本地依赖是否正常。
