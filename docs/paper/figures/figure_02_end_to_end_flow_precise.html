图 2 端到端金融事件分析流程图

输入文本
客户在短时间内发生多笔异常转账，涉及陌生收款账户、异地新设备登录、可疑备注与历史相似风险线索。
常规分析
低风险暂存
高风险回捞
Stage 1事件标准化
Normalizer Agent
□
任务：事件标准化抽取客户、账户、商户、设备、金额、时间与风险信号
● 完成结构化事件生成
Stage 1.5黑名单过滤
Blacklist Filter
✓
任务：三类高危规则匹配人员黑名单、关键词黑名单、高危事件样本
● 相似/命中检查输出 pass 或 hit
Stage 2事件分类
Classifier Agent
◇
任务：事件分类识别反欺诈、反洗钱、贷前风险等业务类型
● 完成事件类型已确定
Stage 3图谱构建
Graph Build
⌘
任务：当前事件图谱构建写入客户、账户、设备、商户、风险信号节点和关系
● 完成Neo4j 证据链生成
Stage 4首次风险评估
First Risk Evaluation
!
任务：多维风险评分结合规则命中、图谱上下文与模型判断生成 risk_score
● 完成输出风险等级与分数
首次评分判断
risk_score ≥ threshold ?
否：低风险流程
是：触发历史回捞
Stage 5A低风险展示
Low-risk Display
✓
任务：低风险结果展示前端展示低风险结论、摘要与基础证据
● 结束展示不进入深度回捞
Stage 5B向量暂存
Milvus Buffer
◎
任务：写入 Milvus 暂存池保存低风险事件向量、摘要和主体信息
● 完成成为后续历史上下文
Stage 6历史回捞
Search Context
⌕
任务：相似历史事件召回从 Milvus 检索同客户、同账户或语义相似事件
● 完成召回历史上下文
Stage 7图谱补全
Graph Enrichment
⌘
任务：历史事件补入 Neo4j补全关联账户、设备、商户与风险信号链路
● 完成风险网络扩展
Stage 8二次风险评估
Second Risk Evaluation
!
任务：二次风险评分结合当前事件、历史回捞结果和补全图谱重新评估
● 完成输出二次 risk_score
Stage 9趋势预测
Trend Prediction
↗
任务：趋势报告生成给出风险趋势、证据摘要与处置建议
● 完成生成可读报告
Stage 10人工复核
Human Review
人
任务：前端展示与复核动作展示风险等级、图谱、报告，支持冻结、放行、误报标记
● 闭环完成复核结果本地留痕
进入 Dashboard 展示最终结果
