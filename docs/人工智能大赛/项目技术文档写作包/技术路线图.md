# 技术路线图

项目名称：基于端侧 AI 的银行零售反欺诈与反洗钱风险多智能体预警系统

## 1. 总体链路

```text
银行零售风险事件输入
  -> 事件标准化与实体识别
  -> Milvus 黑名单三路过滤
       -> 人员黑名单匹配
       -> 风险关键词匹配
       -> 历史事件样本语义匹配
  -> 本地大模型风险分类
  -> RAGFlow 金融知识库检索
  -> bge-m3 向量召回
  -> bge-reranker-v2-m3 重排序
  -> Graphiti + Neo4j 时序知识图谱构建
  -> 多智能体风险评估
  -> 高风险事件触发历史回捞与二次研判
  -> 风险预警、证据摘要、人工复核闭环
```

## 2. 模型与数据分工

| 模块 | 采用方案 | 主要作用 |
|---|---|---|
| 本地大语言模型 | Qwen3.6-35B-A3B Q6_K_M 量化 | 事件理解、风险分类、证据归纳、处置建议生成 |
| 向量模型 | bge-m3 | 金融制度、风险案例、历史事件的语义向量化与召回 |
| 重排序模型 | bge-reranker-v2-m3 | 对召回候选证据进行相关性精排，减少噪声证据 |
| 向量数据库 | Milvus | 存储黑名单、历史事件、审核动作和语义向量 |
| 知识图谱 | Graphiti + Neo4j | 表达客户、账户、交易、设备、风险标签之间的时序关系 |
| 前后端系统 | FastAPI + Vue3 | 提供事件分析、风险看板、人物图谱、黑名单管理和系统状态页面 |
| 知识库 | RAGFlow | 管理金融监管规则、反洗钱案例、银行业务知识等文档 |

## 3. 多智能体职责划分

| 智能体/阶段 | 输入 | 输出 | 说明 |
|---|---|---|---|
| 事件标准化智能体 | 原始事件文本 | 结构化事件对象 | 抽取客户、账户、金额、时间、交易行为和风险线索 |
| 黑名单过滤智能体 | 结构化事件 | 黑名单命中结果 | 判断人员、关键词、历史样本是否命中高风险规则 |
| 分类智能体 | 事件文本与上下文 | 风险类别 | 识别反欺诈、反洗钱、贷前欺诈、异常交易等类别 |
| 图谱构建智能体 | 事件实体和关系 | 图谱节点与边 | 写入 Neo4j，形成客户关系和交易时序网络 |
| 检索增强智能体 | 当前事件 | 相关制度、案例、历史事件 | 使用 bge-m3 召回并用 reranker 精排 |
| 风险评估智能体 | 事件、图谱、检索证据 | 风险等级、风险分、证据链 | 给出可解释的初次研判结论 |
| 历史回捞智能体 | 高风险主体和语义线索 | 关联历史事件 | 从 Milvus 召回同客户、同账户或语义相近事件 |
| 二次研判智能体 | 当前事件和补图结果 | 二次风险评估 | 判断组合风险和反洗钱可疑模式 |
| 报告智能体 | 风险评估结果 | 调查摘要和处置建议 | 面向风控人员输出可读报告 |

## 4. 建议架构图画法

画图时可以分成四层：

1. 应用层：风险分析工作台、事件库、人物图谱、黑名单管理、系统状态。
2. 智能体编排层：标准化、分类、检索、图谱、风险评估、二次研判、报告生成。
3. 模型与知识层：Qwen3.6-35B-A3B Q6_K_M、bge-m3、bge-reranker-v2-m3、RAGFlow、Milvus、Neo4j。
4. 端侧硬件层：CPU 调度、GPU 大模型推理、NPU 轻量预筛或低功耗监控、统一内存和本地存储。
