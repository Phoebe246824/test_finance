# 4 参考资料

本项目在设计和实现过程中参考了大语言模型、向量检索、重排序、知识图谱、向量数据库、RAG 系统、Web 工程框架和金融风控相关资料。正式提交前，应根据实际引用情况补充完整链接、访问日期和论文信息。

## 4.1 模型与算法资料

1. Gemma 系列大语言模型相关技术资料。用于了解 Gemma 模型能力、部署方式、上下文长度、量化推理和提示词设计。
2. Gemma-4-12B-it Q4_K_M 量化模型相关说明。用于本项目本地大语言模型推理。
3. unsloth/gemma-4-12b-it-GGUF 量化模型资料：`https://hf-mirror.com/unsloth/gemma-4-12b-it-GGUF`。用于本地 Q4_K_M 量化模型推理基准测试。
4. BAAI bge-m3 向量模型相关资料。用于金融知识库、历史事件和黑名单样本的语义向量化。
5. BAAI bge-reranker-v2-m3 重排序模型相关资料。用于候选证据精排和检索质量提升。
6. RAG 检索增强生成相关论文和技术文档。用于构建知识库检索、证据引用和大模型推理结合方案。
7. 多智能体系统和 Agent 工作流相关资料。用于设计事件标准化、检索、图谱、风险评估和报告生成等阶段。
