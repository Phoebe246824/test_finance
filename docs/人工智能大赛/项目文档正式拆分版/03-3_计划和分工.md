# 3.3 计划和分工

## 3.3.1 项目计划

结合初赛提交要求，项目计划分为五个阶段推进：

| 阶段 | 时间安排 | 主要任务 | 交付成果 |
|---|---|---|---|
| 第一阶段：项目梳理 | 第 1 周 | 梳理比赛要求、明确项目定位、整理项目代码和技术路线 | 项目题目、文档框架、技术路线图 |
| 第二阶段：模型接入 | 第 2 周 | 联调 Gemma-4-12B-it Q4_K_M、bge-m3、bge-reranker-v2-m3 | 本地推理、向量召回和重排序链路 |
| 第三阶段：系统完善 | 第 3 周 | 完善风险事件闭环、知识图谱、历史回捞和前端展示 | 可演示原型系统 |
| 第四阶段：实验评测 | 第 4 周 | 构建测试样本，采集延迟、tokens/s、显存占用、召回率等指标 | 实验结果、截图和辅助材料 |
| 第五阶段：材料制作 | 第 5 周 | 完成项目文档、作品简介、PPT、视频和压缩包 | 初赛提交材料 |

## 3.3.3 文档、PPT 和视频分工

| 材料 | 负责人 | 内容要求 |

| 作品简介 | 赵晓月 | 300 字以内，突出场景、技术路线和价值 |
| 项目文档 | 赵晓月主写，孙嘉陆、洪鑫宇补充 | 按比赛模板写清项目概况、规划、实施方案和参考资料 |
