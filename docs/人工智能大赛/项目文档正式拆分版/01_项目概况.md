# 1 项目概况

本项目题目为“基于端侧 AI 的银行零售反欺诈与反洗钱风险多智能体预警系统”。项目面向银行零售业务中的个人账户交易、信用卡消费、消费贷申请、远程开户、客户身份识别和反洗钱调查等场景，针对传统规则系统在复杂组合风险识别、历史线索串联、风险证据解释和隐私数据本地处理方面的不足，设计并实现一个端侧部署的金融风控智能体系统。

系统以本地量化大语言模型为推理核心，采用 Gemma-4-12B-it Q4_K_M 进行事件理解、风险分类和调查摘要生成，采用 bge-m3 进行知识库和历史事件向量化召回，采用 bge-reranker-v2-m3 对候选证据进行重排序。系统工程上结合 Milvus、RAGFlow、Graphiti + Neo4j、FastAPI 和 Vue3，形成从原始事件输入到风险预警、证据链展示和人工复核的闭环流程。

项目当前已有代码基础位于：


现有原型已包含风险分析、事件库、人物图谱、黑名单管理、系统状态、审计日志、模型服务配置等功能页面，并具备事件标准化、黑名单过滤、风险分类、向量检索、知识图谱构建、历史事件回捞和二次研判等核心模块。
