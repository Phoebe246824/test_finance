# 2 项目规划

本项目规划围绕“可演示原型、可验证指标、可解释证据、可复现部署”四个目标展开。参赛期间，团队将在现有项目代码基础上完成本地模型部署、风险研判链路完善、测试样本构建、Inference 指标采集、项目文档撰写、PPT 制作和演示视频录制。

项目规划的核心思路如下：

1. 以银行零售反欺诈与反洗钱为主要垂直场景，避免将系统泛化为普通问答应用。
2. 以端侧部署为技术特色，突出金融隐私数据本地处理和弱网可运行能力。
3. 以多智能体流程为系统主线，覆盖事件标准化、黑名单过滤、风险分类、知识检索、图谱构建、历史回捞、二次研判和报告生成。
4. 以 RAG 和知识图谱为证据增强方式，提升模型输出的可追溯性。
5. 以实验指标体现 Inference 效果，包括延迟、tokens/s、显存占用、召回率、准确率等。
