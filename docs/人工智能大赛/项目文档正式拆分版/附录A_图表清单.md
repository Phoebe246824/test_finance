### 图 3 多智能体风险研判流程图

位置：3.2.1 或 3.2.2。

形式：横向流程图，核心是“高风险后触发历史回捞和二次研判”。

建议流程：

```text
原始事件输入
 -> 事件标准化
 -> 黑名单三路过滤
 -> 风险分类
 -> RAG 检索与重排序

 -> 首次风险评估
 -> 是否高风险？
      否 -> 入库留存/低风险展示
      是 -> Milvus 历史回捞 -> 批量补图 -> 二次研判 -> 风险报告与人工复核
```

图中可以把“是否高风险？”画成菱形判断节点。

正文引用写法：


### 图 5 知识图谱与历史回捞机制图

位置：3.2.6 知识图谱与历史回捞。

形式：左侧当前事件，右侧历史事件库和知识图谱，中间用“高风险触发”连接。

建议画法：

```text
当前高风险事件
  -> 提取客户/账户/设备/收款方
  -> 首次构图 Neo4j
  -> 首次风险评估超过阈值
  -> Milvus events 历史回捞
       -> 同客户事件
       -> 同账户事件
       -> 语义相似事件
  -> 批量补图到 Neo4j
  -> 二次研判
  -> 风险证据链
```

图谱部分建议画几个节点：客户 P101、账户 A001、设备 D01、收款方 M01、历史交易 T001/T002，以及风险标签“资金拆分”“异常设备”。

正文引用写法：

```text
知识图谱与历史回捞机制如图 5 所示。
```
