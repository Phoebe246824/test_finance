# 3 实施方案

本项目实施方案围绕数据、行业知识、模型、算法、硬件和系统工程展开，重点说明项目的技术可行性、核心技术细节、预期指标和计划分工。

实施方案总体流程如下：

```text
原始金融风险事件
  -> 事件标准化
  -> 黑名单人员/关键词/事件样本过滤
  -> Gemma-4-12B-it Q4_K_M 风险分类
  -> RAGFlow 金融知识库检索
  -> bge-m3 向量召回
  -> bge-reranker-v2-m3 证据重排序
  -> Graphiti + Neo4j 时序知识图谱构建
  -> 首次风险评估
  -> 高风险触发历史事件回捞
  -> 批量补图与二次研判
  -> 风险预警、证据摘要和人工复核
```

系统采用本地化部署方式，核心组件包括 FastAPI 后端、Vue3 前端、Milvus 向量数据库、RAGFlow 知识库、Graphiti + Neo4j 知识图谱、本地量化大模型、向量模型和重排序模型。系统总体架构如图 2 所示，端到端风险研判流程如图 3 所示。

本章包含技术可行性分析、技术细节、计划和分工三部分。
