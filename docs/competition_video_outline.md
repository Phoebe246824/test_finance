# Sentinel Edge 演示视频 Outline（决赛版，≤3 分钟）

> 赛题：AMD 赛题一·金融垂直方向。配合 [PPT 大纲](competition_ppt_outline.md) 与 [简版脚本](demo_script.md) 使用。
>
> **决赛视频三项硬性要求**（赛题原文 2.决赛阶段·演示视频）——本 outline 逐项落点：
> - ① 用户交互流程 → 镜头 3、4、5
> - ② 本地推理过程和响应效果 → 镜头 2、4
> - ③ 资源监控/性能测试片段 → 镜头 2、6
>
> ⚠️ 所有 `「…」` 为占位，替换为实测值/真实画面；NPU 未落地则不出现在画面与口播中，只讲 GPU。

## 总体设定

- **时长**：2:55–3:00（卡在 3 分钟内）。
- **画面**：屏幕录制为主（前端 + 终端），左上角常驻角标「AMD Ryzen AI MAX+ 395 · 100% 本地推理」。
- **声音**：中文口播旁白 + 轻背景乐；终端关键输出可短暂放大。
- **主线案例**：`finance_01`（低风险暂存）→ `finance_04`（反洗钱高风险 + 历史回捞 P102），讲清"组合风险"卖点。
- **诚实红线**：开拍前确认 `.env` 已切到本地 llama.cpp(ROCm) 端点；`/system` 页 endpoint 必须显示本地地址，不能露出云端 URL。

## 镜头分解

### 镜头 1 · 开场与定位（0:00–0:18）

- **画面**：标题动画 → Dashboard 总览页〔素材 #1〕。
- **旁白**：*"Sentinel Edge，运行在 AMD 锐龙 AI MAX+ 工作站上的端侧金融风控智能体。客户交易、账户关系、贷前资料全部本地处理，数据不出银行内网。"*
- **落点**：抛出"端侧 + 隐私"主张。

### 镜头 2 · 本地环境与硬件证据（0:18–0:48）〔硬性要求 ②③〕

- **画面**：
  - 终端运行 `uv run python scripts/sentinel_competition_demo.py`，展示 JSON 报告〔素材 #7〕，高亮 `target_platform`、`gpu_backend=rocm`、本地 `llm_endpoint`、量化模型名。
  - 切到 `/system` 系统状态页，展示硬件画像。
  - **分屏**右侧开 `rocm-smi`〔素材 #5〕，显示 GPU 在线、显存可用。
- **旁白**：*"模型通过 llama.cpp 的 ROCm 后端运行在 Radeon GPU 上，量化为 INT4。系统状态页与 rocm-smi 实时显示本地端点和 GPU 资源。"*
- **落点**：证明本地 + GPU，奠定"硬件特性"与"资源监控"得分。

### 镜头 3 · 低风险暂存：建立行为基线（0:48–1:18）〔硬性要求 ①〕

- **画面**：`/analysis` 页粘贴 `finance_01`（工资入账/日常消费）→ 点击分析 → 结果显示低风险、未命中高危规则、写入 Milvus 暂存池。
- **旁白**：*"一条正常工资入账事件未命中风险规则，被存入本地行为基线，而不是丢弃——这是后面发现组合风险的关键。"*
- **落点**：展示用户交互 + 暂存机制创新点。

### 镜头 4 · 高风险触发 + 历史回捞（1:18–2:10）〔硬性要求 ①②，核心高潮〕

- **画面**：粘贴 `finance_04`（反洗钱可疑交易）→ 分析。逐步展示：
  1. 本地 LLM 分类 + 多维风险评分（7 维权重，首次风险分）；
  2. Graphiti+Neo4j 单条构图；
  3. **从 Milvus 回捞同客户 P102 的历史分拆转账线索**，批量补图；
  4. 交互式图谱〔素材 #3〕上人—账户—设备关系网随回捞展开。
- **旁白**：*"高风险事件触发后，系统自动回捞该客户的历史分拆转账，补全关系图谱——单看当前交易不算异常，但结合历史就是典型的结构化洗钱。本地 LLM 在「XX」秒内完成整条研判。"*
- **落点**：展示多步智能体 + 组合风险发现 + 本地推理响应速度。

### 镜头 5 · 二次研判与调查摘要（2:10–2:35）〔硬性要求 ①〕

- **画面**：事件详情页展示二次风险分、关联上下文、Dashboard Agent 输出的**反洗钱调查摘要 + 证据点 + 处置建议**；可顺带点一下人物图谱〔素材 #4〕。
- **旁白**：*"补图后系统二次评分并生成调查摘要，给出可疑证据点和处置建议，分析员只需做最终复核。"*
- **落点**：闭环价值——把分析员工作流自动化。

### 镜头 6 · 性能 / 能效 / 隐私收束（2:35–3:00）〔硬性要求 ③〕

- **画面**：
  - 快闪性能数字卡片〔素材 #8/#10 数据〕：「端到端 XX s · XX tokens/s · GPU 峰值 XX% · 显存 XX GB」；
  - 一闪脱敏前/后日志对比〔素材 #9〕；
  - 回到角标 + Logo 收尾。
- **旁白**：*"INT4 量化在本地实现「XX tokens/s」吞吐；日志对身份证、卡号、手机号自动脱敏。隐私不出内网、GPU 本地加速、交易知识库持续沉淀——这就是 Sentinel Edge。"*
- **落点**：补齐性能能效 + 隐私安全两块评分，呼应开场。

## 制作注意

- **先备素材**：镜头依赖的 #5/#6/#9 需实测截图、#8/#10/#11/#12 需先产出（见 PPT 大纲「图片素材清单」）。
- **录屏前置**：服务全部起好、黑名单种子已 seed、`finance_01/04` 预演通过，避免现场报错。
- **节奏**：镜头 4 是高潮，可占足时间；镜头 2、6 的终端/数字用短特写，别让旁白拖。
- **时长兜底**：若超 3 分钟，优先压缩镜头 1 与镜头 6 的旁白，保住镜头 4 的回捞演示。
- **诚实**：不出现 NPU 实测画面（未落地）；不出现任何云端 URL；性能数字必须是真实录制当次的值。
